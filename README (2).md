
# AI Cyber Security Lab Assignment 3

## Project Title
Classifying Cyber Activity Using a Simple Neural Network

## Objective
To classify cyber activities as Normal or Attack using a Dense Neural Network and compare its performance with a Decision Tree.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- TensorFlow / Keras
- Scikit-learn
- Matplotlib

## Dataset Features
- Failed Logins
- Login Hour
- New Device
- Data Transfer (MB)
- Label (Normal / Attack)

## Models Implemented
1. Dense Neural Network (4-8-4-1)
2. Decision Tree Classifier

## Tasks Completed
- Dataset preparation and normalization
- Neural Network training for 20 epochs
- Accuracy and loss visualization
- Test evaluation
- New cyber activity predictions
- Decision Tree comparison
